#Reporte de visión

## Descripción general 

Patital Online es un programa creado para ayudar a MEPEGA con el registro y manejo de las PQRS( Peticiones, Quejas, Reclamos y Sugerencias).

El programa permitiRÁ guardar los datos de las personas que realizan las solicitudes y la información de cada PQRS. también tendrá un número de radicado para identificar cada solicitud. La información se guardara en archivos separados según el tipo de PQRS.
