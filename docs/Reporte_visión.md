# Reporte de visión

## Descripción general 

Patital Online es un programa creado para ayudar a MEPEGA con el registro y manejo de las PQRS( Peticiones, Quejas, Reclamos y Sugerencias).

El programa permitiRÁ guardar los datos de las personas que realizan las solicitudes y la información de cada PQRS. también tendrá un número de radicado para identificar cada solicitud. La información se guardara en archivos separados según el tipo de PQRS.

## Objetivo 

Crear un programa en Python que permita registrar y organizar las PQRS que reciba MEPEGA, facilitando el manejo y consulta de la informacion.

## Beneficios 

*Tener la información de las PQRS más organizada.
*Facilitar el registro de las solicitudes.
*permitir consultar la información guardada
*identificar cada solicitud mediante su número de radicado
*reducir el manejo de la información solamente en papel
