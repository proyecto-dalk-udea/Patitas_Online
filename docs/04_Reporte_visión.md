# Reporte de visión

## Descripción general 

Patitas Online es un programa creado para ayudar a MEPEGA con el registro y manejo de las PQRS( Peticiones, Quejas, Reclamos y Sugerencias).

El programa permitirá guardar los datos de las personas que realizan las solicitudes y la información de cada PQRS. También tendrá un número de radicado para identificar cada solicitud. La información se guardará en archivos separados según el tipo de PQRS.

## Objetivo 

Crear un programa en Python que permita registrar y organizar las PQRS que reciba MEPEGA, facilitando el manejo y consulta de la información.

## Beneficios 

* Tener la información de las PQRS más organizada.
* Facilitar el registro de las solicitudes.
* Permitir consultar la información guardada.
* Identificar cada solicitud mediante su número de radicado.
* Reducir el manejo de la información solamente en papel.
