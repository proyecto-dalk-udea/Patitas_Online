# EVIDENCIAS DE PRUEBAS – PATITAS ONLINE

Esta carpeta contiene las evidencias de las pruebas funcionales realizadas al programa Patitas Online en Google Colab.

Las pruebas incluyen:

- Registro de peticiones, quejas, reclamos y sugerencias.
- Generación de radicados y comprobantes.
- Consulta de solicitudes.
- Actualización de estados.
- Generación de reportes.
- Validación de datos.
- Verificación de fechas y vencimientos.

Los resultados de estas pruebas se encuentran documentados en el archivo `09_Pruebas_Funcionales.md`.
